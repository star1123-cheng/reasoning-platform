# 構想：分層提示，讓學生自己找出規律

狀態：27 種密碼都已改成分層提示卡（2026-10-26）；B（提示程度選單）、C（更新規格書）尚未進行

## 問題

目前學習單的「解碼提示（發給學生）」直接附上完整對照表（例如豬圈密碼的符號表），學生只要逐字查表照抄，沒有用到推理。對照表應該留到最後，當作卡關時的保底。

## 可行做法（由易到難）

1. **給空白格子，讓學生自己填字母**（最適合豬圈密碼）
   - 只發兩個井字格、兩個 X 字格（其中各一個加點），加上規則：「字母從 A 開始依序填進格子」。
   - 學生畫完會自己發現：符號就是字母所在格子的外框形狀。
2. **已知明文**：先給 2～3 個已解出的字母或單字（例如「第一個字是 THE」），讓學生從已知推出其他符號。
3. **情境線索**：用故事暗示單字（例如「鑰匙藏在家具底下」→ UNDER、DESK），學生拿猜到的字核對符號。適合搭配密室逃脫。
4. **分層提示卡**（最推薦，所有密碼都適用）：學生卡住時才逐張翻開。

   | 層級 | 內容（以豬圈密碼為例） |
   |---|---|
   | 提示 1 | 方向：「每個符號都是某個格子的一部分」 |
   | 提示 2 | 已知例子：「T = >，E = □」 |
   | 提示 3 | 空白格子＋填字規則 |
   | 提示 4 | 完整對照表（保底） |

   老師可規定「翻一張提示扣一分」；密室逃脫中可用「時間代價」換提示。
5. **頻率分析**（進階）：最常出現的符號很可能是 E。句子太短不準，只當額外挑戰。

## 實作方向（尚未決定）

- 在「列印學習單」旁加「提示程度」選單：完整對照表／分層提示卡／只給規則／不給提示。
- 目前 27 種密碼的提示由各自的 `encrypt()` 回傳 `hint`（見 `src/ciphers/`），全部改成分層工作量大，建議分批：先豬圈密碼，再凱薩、跳舞小人等常用替換密碼。

已完成：27 種密碼的提示都改成 3～4 張分層提示卡（`HintBlock` 新增 `levels`、`pigGrid`；共用工具在 `src/ciphers/util.ts` 的 `levels()`、`exampleTable()` 等）。順序是「方向 → 已知例子 → 規則 → 完整對照表」；解題本來就需要的材料（比爾密碼的書、Playfair 等方陣）不算答案，一直顯示在提示卡上方。畫面上逐張翻開，列印時全部印出、虛線框可剪開。

注意：維吉尼亞、博福特的金鑰和以前一樣不出現在提示裡（只在出題者備註），需要老師另外給。

原本的三個起點：

- A. 只做「分層提示卡」，先套用在豬圈密碼上試效果。
- B. 直接加「提示程度」選單，先支援幾種常用密碼。
- C. 先修改規格書（`reasoning-platform-spec.md`），把設計寫清楚再動手。
